# Arizona SWAG LogsParser Helper

[![Manifest Version](https://img.shields.io/badge/Manifest-V3-orange.svg)](#)
[![License](https://img.shields.io/badge/AGPL_3.0-green.svg)](#)

**Arizona SWAG LogsParser Helper** - браузерное расширение для Chromium-совместимых браузеров, которое упрощает и автоматизирует работу с логами проекта Arizona SWAG на домене `https://logsparser.cypher-team.com`.

Расширение структурирует отображаемую информацию, добавляет инструменты анализа сессий игроков, детекции подозрительной активности и ускоряет рутинные проверки для технической администрации. Сообщество проекта - форум `https://forum.arizona-swag.com`.

---

## ⚡ Основные возможности

### 🎨 Кастомизация интерфейса и визуальные улучшения
* **Индивидуальная стилизация:** выбор тем оформления (тёмная/светлая), цветовых схем (Arizona Red, Ocean, Emerald, Gold, Frost, Dracula, Sunset, Cyberpunk, Nord, Matrix) и радиуса закругления элементов. Поверхности остаются нейтральными, меняется только акцент.
* **Своя цветовая тема:** отдельные палитры для светлого и тёмного режима, настройка акцентных цветов, фона, карточек, таблиц, текста и границ с мгновенным предпросмотром.
* **Оптимизация пространства:** закрепление навигационной панели и шапки таблицы, скрытие бокового меню, удаление верхних отступов, замена стандартного Favicon.
* **Управление столбцами:** кнопки быстрого скрытия/показа колонок данных и IP-адресов прямо из заголовка таблицы.
* **Плавающий фильтр:** быстрый вызов модального окна фильтрации при прокрутке страницы.

### 🕵️‍♂️ Анализ данных и инструменты пробива
* **Расчёт игрового онлайна:**
  * анализ времени сессий за выбранный период для одного или нескольких игроков;
  * настройка «чистого» онлайна с учётом заданного промежутка времени суток для будней и выходных;
  * **скрытный режим:** сбор статистики онлайна по общим логам выхода без прямой фильтрации по никнейму.
* **Пробив наказаний и репортов:** сбор выданных наказаний и статистики ответов на репорты для группы администраторов с поиском по содержимому.
* **Пакетный пробив IP и ID:**
  * получение последнего и регистрационного IP-адресов по логам выхода;
  * сопоставление числовых ID аккаунтов с их Nick_Name.
* **Интеграция с GeoIP:** определение страны, города, провайдера и типа сети (мобильный, хостинг, прокси/VPN). Расчёт приблизительного расстояния между точками авторизации с цветовой индикацией критических значений.

### 🤖 Аналитика и детекция нарушений
* **Проверка Email на ботов:** определение дубликатов почтовых ящиков с настраиваемым порогом повторений и многоуровневой цветовой индикацией риска.
* **Детекция TG/VK ботов:** выявление подозрительных регистраций и привязок нескольких аккаунтов к одному профилю Telegram или VK.
* **Контроль деталей тюнинга:** автоматическое сканирование логов на установку тюнинга, подсветка строк по заданным временным паттернам (минуты/секунды), поддержка звуковых оповещений при совпадении.
* **Детекция идентичных IP:** выделение строк с одинаковыми IP-адресами в рамках таблицы авторизаций.

### 📋 Автоматизация действий и копирование
* **Генератор команд (Менеджер форм):** шаблонизация наказаний (например, `/banoff 0 {nick} 2000 Чит`) с автоподстановкой ников из таблицы и пакетным копированием готового списка.
* **Умное копирование:**
  * копирование всей строки лога в один клик;
  * копирование отдельных ячеек без служебных символов и GeoIP-приписок;
  * экспорт всех логов текущей страницы в буфер обмена.
* **Маскировка данных:** скрытие конфиденциальной информации (частичное скрытие символов IP, Email, Telegram, VK) на экране и при копировании текста.
* **Шаблоны поисковых запросов:** сохранение часто используемых фильтров логов для быстрого применения в будущем.

### 🧾 Работа с формами и IP
* **Разбор формы 1-9:** вставка текста или загрузка `.txt`, автоматическое распознавание ника, городов, провайдера, месяца регистрации, донатов, скриншотов и соцсетей.
* **Автоматическая сверка с логами:** попап сам запрашивает логи по нику (от старых к новым и от новых к старым), сравнивает первый лог с заявленной датой регистрации, проверяет регистрационный и последний IP, города, провайдера, привязки соцсетей и платежи.
* **Готовый вердикт:** `Похоже на правду`, `Есть нестыковки` или `Похоже на ложь`. Каждое поле формы получает свой статус, а все расхождения показываются отдельными карточками.
* **Проверка IP вручную:** GeoIP по кнопке, определение города, провайдера, хостинга, VPN и мобильного оператора.
* **Быстрые переходы:** открытие логов по нику, IP или почте прямо из попапа.

## 📦 Установка расширения

### Ручная установка из исходного кода

1. Скачайте архив с кодом проекта или клонируйте репозиторий.
2. Откройте браузер Google Chrome (или любой другой на базе Chromium) и перейдите на страницу расширений: `chrome://extensions/`.
3. Включите **Режим разработчика** (Developer mode) в правом верхнем углу.
4. Нажмите кнопку **Загрузить распакованное расширение** (Load unpacked) в левом верхнем углу.
5. Выберите папку, содержащую файлы проекта (в которой находится `manifest.json`).

---

## ⚙️ Первичная настройка

1. Перейдите на страницу логов `https://logsparser.cypher-team.com/`.
2. Нажмите на иконку расширения на панели инструментов браузера, чтобы открыть всплывающее окно (Popup).
3. Во вкладке **«Оформление»** настройте отображение интерфейса.
4. Во вкладке **«Инструменты»** включите необходимые детекторы, настройте паттерны сканирования тюнинга, параметры маскировки и пороги для проверки почтовых ящиков.
5. Во вкладке **«Формы/IP»** вставьте форму игрока и нажмите «Разобрать». Сверка с логами запустится автоматически.
6. Для ручной проверки IP воспользуйтесь полем ввода в нижней части вкладки «Формы/IP».

Ссылки на логи и форум проекта доступны в нижней части попапа.

## 🔒 Безопасность и конфиденциальность

* Настройки пользователя сохраняются локально на устройстве с использованием `chrome.storage.local`.
* Запросы к сервису GeoIP (`ip-api.com`) проходят через внутреннюю очередь с задержкой, минимизируя передачу лишних данных.
* Функция маскировки позволяет безопасно делать скриншоты страниц логов для жалоб, не компрометируя личные данные игроков (IP, почты, привязанные соцсети).
